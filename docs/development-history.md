# 開発の変遷

過去の未コミット作業を2026-10-08に機能単位で整理しています。以下は実装のテーマ順であり、各機能が書かれた時刻の復元ではありません。
履歴は `git log --oneline --reverse`、詳細は `git show <commit>` で確認できます。

1. 初期PoC: TexTeller / UniMERNet比較、FastAPI、手書きデータ収集、評価・集計を整備。
2. Phaser + TypeScriptへゲーム画面を分離。低遅延の認識APIとWindowsの展示向け起動・梱包を導入。
3. 50問のJSON問題バンク、7難易度、検証・問題編集APIを導入。正答・許容表記・解説を中央管理。
4. 3モード、Display/Controller分離と同期、古い接続の回復、二重提出防止を導入。
5. スコア加点を廃止し正解数・連続正解・正解率に整理。終了理由の明示とモード説明画面を追加。
6. 全画面、狭い画面の操作領域、数式の中央配置・縮小・タイマー拡大を調整。無制限モードは拡大しない。
7. CUDAコンテキスト異常後の認識ワーカー再生成を導入。
8. 展示前の全問題・モード×難易度・連続プレイ・サイズ変化・API異常系テストを拡張。
9. cloneからのセットアップを失敗時停止・CPU/GPU選択・固定依存・準備完了チェックへ整理し、運用手順を整備。
10. 配布先向けの目次とCPU/GPU別スクリプトを追加。CPU専用venvを新規導入し、公開画像32要求・同時要求30回・オフライン設定5回の実測を記録。
11. 運用方針をgit clone / git pullへ統一。READMEをプロジェクト概要から始める構成へ整理し、モデル比較・評価の詳細は別ガイドへ分離。

設計判断は `docs/adr/`、過去のUI検証は `reports/`、展示前検証は `reports/exhibition_release_validation_2026-10-08.md` を参照。
将来は1つの目的ごとに実装・テスト・関連文書をまとめてコミットし、検証結果を実施日と対象環境付きで残します。
依存更新・UI調整・機能変更は可能な限り別の履歴にします。未検証の性能向上をコミット説明で断定しません。
