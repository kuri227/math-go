# 数学でGO v0.1.0-alpha.1

文化祭での公開を目標に開発中の、最初の配布検証用Pre-releaseです。

## この版で確認できること

- TexTellerによる手書き数式認識
- 5問の時間制限なし練習
- 7問・1問30秒のチャレンジ
- 正規化LaTeXと登録済み別表記による正答判定
- スコア、連続正解、残機、結果表示
- マウス、ペン、タッチ入力

## Windowsでの導入

1. ZIPを展開する。
2. PowerShellで展開先を開く。
3. `Set-ExecutionPolicy -Scope Process Bypass` を実行する。
4. `.\scripts\setup_festival.ps1` を実行する。
5. `.\scripts\start_festival.ps1` を実行する。

初回セットアップにはインターネット接続が必要です。モデル本体、Python仮想環境、個人の筆跡データはZIPに含まれません。

## 既知の制約

- 正式版ではなく、配布手順を検証するための開発版です。
- NVIDIA GPU搭載Windows PCを対象にしています。
- 一般的な数学的同値判定には未対応です。
- 複数端末利用と長時間連続稼働は追加検証が必要です。
- プレイ前後のUX、問題構成、難易度は今後変更します。
