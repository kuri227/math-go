# モード説明画面の設計記録

記録日: 2026-10-08。既存の開始フローに説明画面を追加する局所的な拡張。視覚の基準は既存 `DESIGN.md`、プロダクトの基準は `PRODUCT.md` とする。新しい視覚世界や全体のトークン定義は導入せず、`DESIGN.md` と `.impeccable/design.json` は更新しない。

## 方向契約

ユーザーが選択した順序は「難易度・モードを選択 → 進むボタンで専用画面へ → ゲーム全体と選択モードを軽く説明 → 明示的に開始」。選択画面の進む操作は「このモードの説明へ」、説明画面の主要操作は「ゲームを開始」とし、遷移と開始の意味を区別する。

説明は「問題を見る・答えを書く・判定を確認する」の3手順に続けて、問題数、制限時間、残機、時計の停止、終了条件、残機が減る条件を示す。正解数・連続正解を記録し、終了時には正解数／回答数と正解率を確認できる。点数換算や速度ボーナスは案内しない。

既存の濃紺の舞台、紙色の読む面、M PLUS 1、主要・副次操作のボタン、金色のフォーカス表現を継承する。大画面では遊び方とルールを左右に並べ、760px以下では縦に並べる。ルールを一つの紙面にまとめ、統計を個別の小カード群へ分割しない。小画面ではページ全体をスクロールして説明と開始操作を読む。

## 実装境界

- `game/src/ui/CourseGuide.ts`: Displayと1画面版で共用する説明表示。2画面ではモニター・液タブ、1画面では画面・白い入力欄という案内に切り替える。見出しへフォーカスを移し、準備状態を `role="status"` で伝える。
- `game/src/ui/courseGuideContent.ts`: ゲームが使う `CourseConfig` から問題数・時間・残機・終了条件の文言を生成する。モード固有の数値を説明側へ重複して固定しない。
- `game/src/ui/course-guide.css`: 説明画面内のレイアウトと応答幅を担当する。既存のゲーム・Canvasのレイアウトへ依存させない。
- `game/src/entries/display.ts` と `game/src/main.ts`: 選択、説明、開始の遷移と準備可否を担当する。説明を開く操作ではPhaserを生成せず、時計も開始しない。モデル・問題の先読みは継続する。

「設定に戻る」は選択を維持し、選択画面の進むボタンへフォーカスを戻す。準備中でも説明へ進めるが、開始ボタンは無効とし理由を表示する。DisplayではController接続も開始条件に含める。1画面版のモデル準備失敗時は、選択画面からの準備やり直しを優先する既存の回復操作を保つ。
