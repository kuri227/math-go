# モニター画面：女の子が問題を提示する案

更新日：2026-11-06。敵を倒す画面ではなく、女の子が来場者へ問題を提示するクイズ番組型の構成です。使用素材は`data/img/5EC55D0C-E5A6-433F-AEDF-DCB81C9BAFF4.png`の一枚だけとし、キャラクター画像そのものは動かしたり差し替えたりしません。

## 本番画面の基準案

初稿の画像はローカル資料です。提供イラストと同様、Gitには含めません。

女の子を中央の背面、問題と回答中の筆跡を前面へ配置します。顔とヘッドセットは問題面より上へ出し、衣装と足元を上下から少し見せることで、女の子がボードの後ろに立って提示している奥行きを作ります。

モックアップでは構図へ合わせてキャラクターを再現していますが、実装では元PNGをそのまま表示します。顔、衣装、ポーズを加工せず、`object-fit: contain`と表示位置だけを調整します。

### 表示レイヤー

1. 濃紺のステージ背景と端に置く薄い数式記号
2. キャラクター背面のコーラル色スポットライト
3. 元の透過キャラクターPNG一枚
4. HTML・KaTeXで描画する問題パネル
5. 判定文字、枠線、SVG軌跡などのフィードバック
6. HUDと下部ステータス

問題パネル中央は不透明度96%以上の乳白色とし、問題文へ衣装や背景が透けないようにします。端だけをわずかに透過させ、キャラクターとの奥行きを作ります。

## 一枚絵を固定したアニメーション

初稿の絵コンテもローカル資料です。

絵コンテの全場面で、キャラクターの画像、位置、拡縮、表情は同一です。動くのは問題パネル、枠線、文字、背景光、判定表示だけです。

| 状態 | 動き | 目安時間 |
|---|---|---:|
| 問題登場 | 空の問題面を下からクリップ表示し、上端のコーラル線を左から描く | 320ms |
| 問題表示 | 数式と問題文を軽いぼかしから鮮明にし、筆跡欄のティール線を描く | 220ms |
| 回答中 | 筆跡は即時同期し、枠線を常時動かさない | 継続 |
| 正解 | 回答から問題文へ短いティール線を送り、枠と背景光を一度明るくする | 700ms |
| 不正解 | 筆跡欄だけを左右4px動かし、コーラル枠と「もう一度！」を表示する | 360ms |
| 時間切れ | タイマー線を橙色で閉じ、「時間切れ」を表示してページ送りへつなぐ | 650ms |
| 次の問題 | 古い問題面を左へ退場させ、新しい問題面を右から同じ位置へ入れる | 420ms |

### モーションの中心

問題が「女の子から提示される」瞬間を、この画面の主要な演出とします。問題面が出るたびに大きく跳ねさせず、クリップ表示と上端の細い線で登場を見せます。回答後は色だけでなく、回答と問題の間を短い軌跡で結び、何が判定されたかを観客にも伝えます。

キャラクターは完全に固定します。上下移動、傾き、拡縮、表情差分、まばたき、疑似的な口パクも追加しません。代わりに背面スポットライトの明るさを判定時だけ変えます。これにより元イラストを崩さず、アニメーションの責務をDOM側へ限定できます。

## 実装方針

新しいライブラリは追加せず、既存のDOM、KaTeX、CSS、Web Animations API、SVGで実現できます。

- 問題面の登場：`clip-path: inset()`と`opacity`
- 上端・筆跡枠の描画：SVGの`stroke-dashoffset`
- 問題切り替え：2枚のDOMパネルを重ね、`transform`で入れ替える
- 正解の軌跡：回答位置と問題文位置を結ぶ短いSVG path
- 不正解：筆跡欄だけを`translateX()`し、画面全体は揺らさない
- 時間切れ：橙色の進行線、判定文、ページ送り用の`clip-path`
- キャラクター：静的な`img`要素1個。`src`も`transform`も状態で変更しない

```html
<div class="quiz-stage">
  <div class="quiz-stage__spotlight"></div>
  <img
    class="quiz-stage__host"
    src="/assets/characters/quiz-host.png"
    alt=""
  />
  <section class="quiz-stage__problem"><!-- KaTeXと筆跡 --></section>
  <svg class="quiz-stage__feedback" aria-hidden="true"></svg>
</div>
```

装飾としてのキャラクター画像は`alt=""`とし、問題・時間・判定は必ずDOMの文字でも提示します。`prefers-reduced-motion`ではクリップ移動と軌跡を省き、問題面と判定文を即時表示します。

## レスポンシブ時の扱い

- 16:9：頭部を問題面の上へ十分に出し、足元を下端へ少し見せる
- 4:3：問題面を横幅88%まで広げ、キャラクターを約12%縮小する
- 縦画面：顔を上部中央へ固定し、問題面を画面幅94%へ広げる。衣装と足元は隠してよい
- 長文問題：キャラクターではなく問題面を先に拡大し、顔の下端まで重なっても目とヘッドセットは隠さない

本番実装では、元画像の足元基準点と顔の安全領域をCSSカスタムプロパティで管理します。別の一枚絵へ交換する場合も、`--host-width`、`--host-x`、`--host-y`の3値だけで調整できる構造にします。
