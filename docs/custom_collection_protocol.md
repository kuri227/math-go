# Test B 収集プロトコル

## 目的と停止条件

最初の判定用データは60件とする。人間が実際にWeb Canvasへ書いた入力だけを採用し、生成画像や公開データの転用は行わない。最低2人、できれば3人以上の匿名writerから集め、1人が全体の50%を超えないようにする。マウス、ペン、タッチを可能な範囲で混在させる。

60件に達した時点で、画像・stroke・Ground Truth・manifestの対応、両モデルの実推論、一括評価を確認する。収集経路が安定したら100〜300件へ拡張する。

## 1サンプルの手順

1. 担当者が対象式を確認し、Canvasへ通常の速度で一度だけ書く。
2. 「両モデルで認識する」を押し、同一crop済みPNGがプレビューされたことを確認する。
3. 正解LaTeXを別の担当者または収集後レビューで確認する。
4. カテゴリ、難易度、匿名writer IDを選び、「評価データとして保存」を押す。
5. `data/custom/manifest.csv` の最終行と、対応するPNG/stroke JSONが存在することを確認する。

モデル出力を見てからGround Truthを書き換えてはならない。書き損じは保存せず描き直してよいが、認識が難しそうという理由だけで除外しない。

## 品質確認

- stroke JSONに `x`、`y`、`t`、`pointerType` があり、対応機器では `pressure` も記録されている。
- PNGは白背景・黒線で、数式全体とpaddingを含み、過剰な余白がない。
- `writer_id` は実名・メールアドレス等を含まない。
- 同じ式を複数人が書く場合も各サンプルを独立に保存する。
- 収集対象の式や書き手をモデル出力に合わせて選別しない。
