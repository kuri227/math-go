# 数学でGO 効果音

このディレクトリ直下のWAVは、`scripts/audio/generate_game_sfx.mjs`で事前生成したプロジェクト専用の効果音です。ゲーム中に音を合成する処理はありません。直下の効果音には外部素材・生成AIモデル・第三者ライセンスを使用していません。

CC0の外部BGM候補は本番ビルドへ混入しないよう、リポジトリ直下の`assets/audio-candidates/`へ分離しています。出典と確認事項はそちらのREADMEとルートの`THIRD_PARTY_NOTICES.md`を参照してください。

全8音を、展示会場で繰り返し聞いても驚きにくい柔らかなマレット音として統一しています。角の立つ矩形波・のこぎり波は使わず、正弦波と控えめな三角波、緩やかな減衰、用途ごとの低いピーク値で生成します。残り5秒の`tick.wav`と残り2秒の`tick-urgent.wav`も同じ音色に揃え、緊急音だけが急に鋭くならない設計です。
